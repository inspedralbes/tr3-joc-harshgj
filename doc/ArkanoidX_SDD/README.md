# ArkanoidX — Spec-Driven Development con IA

Práctica: IA amb Desenvolupament Guiat per Especificació (OpenSpec)

## Estructura del repositorio

```
specs/
├── foundations.md    # Contexto, objetivos y restricciones
├── spec.md           # Comportamiento esperado (CRUD UserProfile)
└── plan.md           # Estrategia de implementación en 4 fases

docs/
├── prompts-log.md    # Trazabilidad completa del proceso
└── ArkanoidX_SDD_Report.pdf  # Informe final
```

## Feature implementada
CRUD completo de perfiles de usuario en un juego Arkanoid para móvil (Unity 2022 LTS).
Modos de juego: Solo | Multijugador WebSocket | Contra IA.

## Metodología
Spec-Driven Development (SDD) — especificación primero, implementación guiada por el spec.
